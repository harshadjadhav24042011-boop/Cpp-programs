Assignment 5

Topic: Types of Inheritance

Programming Language: C++

IDE: Dev-C++

Description: This program demonstrates the concepts of single inheritance, multiple inheritance, and multilevel inheritance in C++.

Algorithm

Start the program.

Define the base and derived classes for single inheritance.

Define the classes for multiple inheritance.

Define the classes for multilevel inheritance.

Create objects of the derived classes.

Call the member functions to display the messages.

Stop the program.

Program Structure

Person and Student: Demonstrate single inheritance.

Father, Mother and Child: Demonstrate multiple inheritance.

Animal, Dog and Puppy: Demonstrate multilevel inheritance.

main() Function: Creates objects and calls the member functions of the classes.
