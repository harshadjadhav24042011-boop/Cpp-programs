Assignment: Class Template and Function Template

Programming Language: C++

IDE: Dev-C++

Description

This program demonstrates class templates and function templates in C++. The class template performs addition and multiplication using different data types, while the function template finds the maximum value between two values.

Objectives

To understand class templates and function templates.

To implement generic classes and functions.

To perform operations using different data types.

To understand code reusability in C++.

Algorithm

Define a class template named Calculator.

Implement addition and multiplication functions.

Create objects using integer and double data types.

Define a function template named findMaximum().

Compare two values and return the maximum.

Display the results.

Program Structure

Calculator: Class template that performs addition and multiplication.

findMaximum(): Function template that returns the greater of two values.

main(): Creates objects, calls the function template, and displays the results.

Concepts Used

Templates in C++

Class Templates

Function Templates

Generic Programming

Code Reusability

Files

ClassTemplate.cpp — Demonstrates class templates.

FunctionTemplate.cpp — Demonstrates function templates.

Result

Successfully implemented class templates and function templates in C++ to perform operations on different data types.

Conclusion

This assignment demonstrates how templates make C++ programs reusable and flexible by allowing classes and functions to work with different data types
